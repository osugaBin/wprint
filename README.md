# DrBin Marker - 图片与PDF水印工具

一个现代化的网页工具，为您的图片和PDF添加个性化水印。

## 功能特点

- **多格式支持**：支持 JPG、PNG、GIF 等图片格式和 PDF 文件
- **默认水印**：内置 "DrBin Marker" 作为默认水印文字
- **平铺水印**：默认使用平铺模式，覆盖整个画面
- **6种预设颜色**：白、黑、红、蓝、绿、橙色快速选择
- **精细调节**：
   - 字体大小（12-72px）
   - 透明度（10%-100%）
   - 旋转角度（-90° 到 90°）
- **9宫格定位**：单水印模式下可精确定位（9个位置可选）
- **实时预览**：参数调整即时显示效果
- **批量下载**：文件名自动添加 "BinMark" 后缀

## 技术栈

- HTML5 + CSS3 + JavaScript
- PDF.js（PDF 渲染）
- pdf-lib（PDF 水印处理）
- Canvas API（水印渲染）

## 快速开始

1. 双击 `index.html` 在浏览器中打开
2. 点击上传区域或拖拽文件上传
3. 设置水印参数（已有默认配置）
4. 点击"预览"查看效果
5. 点击"下载"获取带水印文件
